The one word a grandma would text about AI: **Whatchamacallit**.

Grandma has never once remembered the name of a gadget. The remote is the
whatchamacallit, the router is the whatchamacallit, and now the robot that
answers back in full sentences is the whatchamacallit too. She is not
confused about what it does — she is just not learning a new word at her
age, and why should she, when the old one still works? One word, no
explanation, no punctuation, sent exactly the way she would send it.

## Run it

```sh
python3 main.py
```

Output:

```text
Whatchamacallit
```
